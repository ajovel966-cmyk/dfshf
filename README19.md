# 周报憋半小时只挤出三行：搜狗输入法 AI 帮写能接的 6 类活、接不住的 3 类活，附 3 套提示模板与核对清单

上周四下午五点四十，周报文档开着半小时，正文只有三行：「本周完成需求评审」「跟进线上问题」「下周继续」。光标在第四行闪，脑子里全是杂事，就是不知道从哪句开始写。我把这堆流水账原样粘进搜狗输入法的 AI 帮写，让它按「进展—问题—下周计划」重排。四十秒，出来一版条目，骨架能用，但里面有两个数字是它自己编的。

那一下我摸清了边界：**它能把你从「无从下笔」推到「有稿可改」，不能替你保证稿子是真的。** 这篇只聊帮写——什么活交给它、提示词怎么给、出来核对什么、卡住怎么排。版本和各平台开放范围可以先在 [搜狗输入法功能与版本说明页](https://pkepisode.com) 对一遍，同一个版本号在电脑和手机上能调的项不一样。

## 一、入口就两个，别在候选栏里找十分钟

帮写入口有两处：状态栏图标右键，菜单里「AI 帮写」；或在输入框里打下几个字，候选栏末尾的「AI」标识。找不到图标，多半是「属性设置 → 高级 → AI 功能」总开关没开，或停在英文状态——中文没激活时这面板不弹。

面板里排着五个动作：润色、校对、翻译、结构化、续写。我头几天每次只会点「润色」，用完还是流水账。润色只改表达不动结构；重排段落点「结构化」，往下接才用「续写」。

快捷入口可以自己挂：到「属性设置 → 按键 → 自定义快捷键」加组合键，我挂 `Ctrl + Alt + J`，避开常被抢走的 `Ctrl + Shift + X`。写到一半卡住，手不离键盘就能叫出面板。

## 二、六类活它能接，接的方式不一样

同一句「帮我写」落在不同场景里，结果差得远。这一年用得最多的六类活，我列了张表，末列是实际怎么用。

| 场景 | 接不接得住 | 容易出问题的地方 | 我的实际用法 |
| --- | --- | --- | --- |
| 周报、日报的流水账重排 | 接得住，最值 | 自己补数字 | 只让它排序换动词，数字自己填 |
| 会议录音整理成待办 | 接得住，最省事 | 责任人会串 | 会后立刻跑，人名和日期逐条点 |
| 对外邮件软化语气 | 一半 | 把承诺写大 | 只改语气，删掉它加的「保证」「随时」「一定」 |
| 客户问题回复初稿 | 一半 | 事实得你喂 | 先贴原始工单，再让它写 |
| 校对错别字与标点 | 接得住，最稳 | 专有名词被「改对」 | 公司名、项目代号先进「用户词库」，再校 |
| 长文续写、扩写 | 勉强 | 越写越空 | 只拿它补段落之间的过渡句 |

第一行和第五行我每天在用。前者省「排序」这份力气——素材自己攒，它负责收拢；后者省「第二遍读」，人读自己的稿子会跳过错字，机器不会。

## 三、三类活它接不住，硬塞会出事

**带责任口径的文字。** 通知、公告、合同条款、给客户的书面承诺。它会把「三个工作日内回复」写成「尽快回复」，把「视情况而定」写成「一定安排」。语气是顺了，责任也被放大了。

**数字和事实密集的文字。** 金额、比例、日期、工单编号、人名。实测那次原文是「新增 3 个客户」，它输出成「客户量提升 30%」。看着更漂亮，但不是我的数据。稿子里凡是出现数字，默认当成它编的。

**要你下判断的文字。** 绩效评价、道歉、拒绝、催款。分量在于「你敢不敢把那句话说出来」，帮写只给一段谁都能用的圆话，客气，但一个问题没解决。

## 四、三套提示模板，把「帮我写」换成五段式

提示都套一个骨架：**背景 + 素材原文 + 交付形态 + 硬约束 + 反向要求**。收尾那句最有用——写明「不要新增我未提供的数字和人名」，编造明显变少。

**模板 A｜流水账改成周报**

```text
背景：我是[岗位]，本周主要负责[项目A、项目B]。
素材：以下是我这周的流水账，原文照抄：[粘贴]
交付：按「进展 / 阻塞 / 下周计划」三段，每段不超过 4 条，一行一条，动词开头。
约束：只用素材里出现的信息，按重要程度排序。
反向要求：不要新增数字、人名、日期，不要写评价性形容词。
```

**模板 B｜会议记录转待办**

```text
背景：这是一次[周会/需求评审]的记录，参会 5 人。
素材：[粘贴原始记录]
交付：三列——待办、责任人、建议截止时间；责任人只能从素材里的人名里选。
约束：素材里没说清的，写「待确认」，不要替我指派。
反向要求：不要合并两条不同的待办，不要补充素材之外的结论。
```

**模板 C｜对外回复软化语气**

```text
背景：客户反馈[问题]，我要书面回复，客气但不做额外承诺。
素材：[粘贴工单原文和我的草稿]
交付：改写我的草稿，保留全部事实和数字，只调整措辞。
约束：不新增时间承诺，不出现「保证」「随时」「一定」这类词。
反向要求：如果我的草稿里事实不清，直接标出来，不要自己补。
```

三套里最值钱的是模板 B 的「写待确认」和模板 C 的「直接标出来」——把它们从「替我做决定」改成「提醒我该做决定」。

## 五、一次完整跑通：从流水账到能发的周报

1. 打开记事本，把本周干过的事倒着列一遍，一条一行，句子不用通顺，别边写边改。
2. 切到中文输入状态，在正文第一行打下两个字，等候选栏出现，点末尾的「AI」标识。
3. 在面板里选「结构化」，把模板 A 整段贴进去，只替换「素材」那一行。
4. 结果出来**先另存为新内容**。就地接受会覆盖掉流水账，想回退没地方回。
5. 逐条对回原文改数字、人名、日期，至少留三分钟，跳过去等于白做。
6. 把改完的稿子再丢进「校对」跑一遍，专有名词要盯住，它会把不认识的词往常见词上校。
7. 关掉面板，读开头两句，把「圆满」「顺利推进」换成具体动作，比如「接口联调完 3 个」「延期 2 天，卡在等测试环境」。

第 4 步最容易漏：辛苦攒的素材被一段机器文字顶掉，只能凭记忆重打。

## 六、核对就三步，别跳过

- **数字回原文。** 每个百分比、金额、日期、编号，都要能在原始素材里找到对应的一句；找不到就是它编的。
- **专有名词念一遍。** 公司名、产品名、客户简称，出声读一遍。它常把生僻简称换成更常见的词，看着通顺，收件人一眼看出你没用心。
- **结论句反问自己一句。** 「这话我敢在会上说吗？」敢，留着；不敢，删掉重写。这一条比前两条管用——帮写最擅长把没把握的话写得很有把握。

## 七、转圈不吐字、结果被截断：五个排查动作

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 面板点开一直转圈 | 断网，或账号没登录 | 这功能依赖联网，恢复网络、登录后重试 |
| 弹「内容过长，请分段处理」 | 一次塞了几千字 | 按段落切，一次控制在 500 字以内 |
| 输出的字和我原文几乎一样 | 点成了「校对」 | 换成「结构化」或「续写」再跑 |
| 候选栏没有「AI」标识 | 总开关关着，或停在英文状态 | 进「属性设置 → 高级 → AI 功能」打开，切回中文输入 |
| 自定义的快捷键按不动 | 组合键被其他软件占用 | 到「属性设置 → 按键」换一个组合，别用 `Ctrl + Space` |

还有两种不算故障：结果只吐出一段就断了，多半是网络抖了一下，重跑即可；手机端找不到同样的按钮是平台开放范围不同，[按平台整理的功能入口与排查步骤](https://pkepisode.com) 里有对照，别拿电脑截图去手机上找。

顺带一句：别把客户名单、身份证号、合同正文贴进去。它联网，素材会离开你这台机器，这类活我宁可自己写慢点。

## 把它当打字员，别当审稿人

回到那个周四下午。那版稿子我改了十二分钟：删掉两个它编的数字，把「显著提升」换成「接口联调完 3 个」，结构基本照用。省下二十分钟，不多，但足够让我不再拖到下班前才动笔。

这个功能真正解决的是「第一句写不出来」，不是「写得对不对」。把它放在起草那一步，人留在核对那一步，它就是个称职的打字员；指望它替你把关，迟早要在会上替它解释一个不存在的 30%。

想再抠细一点，比如不同版本的面板差异、语音转写怎么和帮写接起来，[各平台 AI 功能的开放范围](https://pkepisode.com) 那份对照可以对着设备看一遍，省得在候选栏里反复找按钮。
