# 公用电脑上收完合同就走？离开前把这七处痕迹清干净，再顺手开三个自动设置

去年十一月，陪朋友去共享办公空间签续租合同。对方把 PDF 发在 Telegram 群里，我用工位那台公用电脑开网页版下载，双击翻了两页条款，合上盖子去前台签字，回来拎包就走了。三天后对方问"补充条款那页你确认过吗"，我才想起来——文件还躺在那台机器的下载文件夹里，名字就叫 `租赁合同_终版.pdf`，下一个坐下来的人双击就能看。

后来我专门跑回去一趟。删文件花了五秒，把机器上其他痕迹清干净花了二十多分钟，因为当时根本不知道该清哪些。这篇就是那二十分钟的产物：一份按位置排的清理清单，加几个装一次就长期生效的设置。

## 删掉文件只是开头，机器记住的比你以为的多

多数人对"删了"的理解就是文件进了回收站。但在公用电脑上，文件本身只是七处痕迹里的一处，而且是最容易处理的那处。

浏览器至少留四样：**下载记录**（`Ctrl + J` 打开，里面写着原始下载地址、文件大小、保存路径，右侧还有个"在文件夹中显示"，等于给下一个人留了导航）；**地址栏补全**（你敲过的域名会一直待在下拉列表里）；**站点数据**（Cookie 和 localStorage，登录态就存在这里）；**磁盘缓存**（页面里预览过的图片、PDF 分片，本地都留了一份）。

系统层面还有两处：资源管理器的"快速访问"和访达的"最近使用"，会把你打开过的文件名平铺出来；剪贴板历史，如果你复制过文件路径或提取码，它可能还留着。

有个细节值得单独讲：Chrome 从 116 版之后把"清除浏览数据"面板拆成了"基本"和"高级"两页，**"Cookie 及其他网站数据"被挪进了"高级"**，默认不勾。我见过不少人只清了"缓存的图片和文件"，回头一刷新页面还是登录状态，以为自己没清干净，其实是压根没清对地方。这类界面差异在 [文件下载位置与管理](https://tlgrlf-web.com) 里有对照说明，第一次上手建议先照图把菜单认一遍，比瞎点省时间。

## 七处痕迹，按这张表逐个过

位置上能留下的都列进来了。第三列写"在哪儿点"，第四列是我自己漏过或差点漏过的细节，比前两列更值得看。

| 痕迹位置 | 留下来的是什么 | 在哪儿清 | 最常漏的细节 |
| --- | --- | --- | --- |
| 文件本体 | 合同、报表、证件照原文件 | 下载记录里点"在文件夹中显示"，删掉后清空回收站 | 重名会产生 `(1)`、`(2)` 副本，只删了一个等于没删 |
| 下载记录 | 原始下载链接、文件名、保存路径 | `Ctrl + J` → 列表右上角"清除下载记录" | 清空列表不等于删文件，反过来也一样 |
| 站点数据 | Cookie、localStorage、登录态 | 地址栏左侧站点图标 → "Cookie 和网站数据" → 管理 → 全部删除 | 只清缓存不清这一项，页面仍是已登录 |
| 磁盘缓存 | 预览过的图片、PDF 分片 | 设置 → 隐私和安全 → 删除浏览数据 → 勾"缓存的图片和文件"，时间范围选"时间不限" | 选"过去 1 小时"基本等于没清 |
| 地址栏建议 | 你输入过的域名与关键词 | 光标移到单条建议上按 `Shift + Delete`；或在"隐私和安全 → 地址栏"里关掉 | 单条删比整体清更精准 |
| 系统"最近使用" | 打开过的文件名列表 | Windows：快速访问里右键"从快速访问中移除"；macOS：访达 → 清除菜单 → 清除最近使用 | 这一处最容易被忘，因为不在浏览器里 |
| 剪贴板与运行历史 | 复制过的路径、`Win + R` 输入过的目录 | `Win + V` → 全部清除；`regedit` 删 `RunMRU` 键下条目 | 输入法自造词里也可能留下文件名 |

顺带说一句缩略图缓存：Windows 在 `%LocalAppData%\Microsoft\Windows\Explorer\` 下有一堆 `thumbcache_*.db`，缩略图模式下能直接看到文件内容预览。要清就打开"磁盘清理"勾上"缩略图"，别手动去删那些文件。

## 离开前的六步，按顺序走不要跳

顺序有讲究：先断登录，再删本地。反过来做的话，你在删文件的过程中页面还在线，缓存又会被重新写回去。

1. **先退出登录，不是先关标签页。** 网页版左侧菜单 → 设置 → 拉到最底 → 退出登录；同时在"设备（有些版本叫活动会话）"里点"终止所有其他会话"。直接关标签页只是断了这个窗口，会话在服务端还挂着。
2. **再看一眼已登录设备列表。** 退干净之后，手机端会收到会话变动提示，顺手在里面把不认识的设备踢掉。完整的设备核对流程可以对着 [共享电脑上的登录与退出流程](https://tlgrlf-web.com) 一步步走。
3. **删文件，顺手核对副本。** 常用路径是 `C:\Users\<用户名>\Downloads`，别只看桌面。删完打开回收站，右键"清空回收站"——很多人只做到"删除"就停了。
4. **清下载记录。** `Ctrl + J`，如果列表里有多条，用列表右上角的"清除下载记录"一次性清掉，比一条条点 × 快。
5. **清站点数据。** 地址栏左侧那个锁形或滑块图标 → "Cookie 和网站数据" → 管理 → 删除。这一步做完，重新打开页面应该要求重新登录，那才算真清对。
6. **清系统层两三处。** 快速访问里的条目、`Win + V` 的剪贴板历史、`Win + R` 的运行历史。这三处加起来不到一分钟，但恰恰是别人最容易看到你干过什么的地方。

做完之后有个验证动作很值得加：**开一个无痕窗口，重新访问一次网页版，确认显示的是未登录状态。** 这是唯一能证明"真退干净了"的办法，比反复检查设置页靠谱。

## 三个设置，让下一台机器自己清

公用电脑不可能每次都靠记性，所以把这几个开关提前打开。它们都是"关闭时清"或"每次询问"这类一次性配置：

1. **Chrome：**设置 → 隐私和安全 → 删除浏览数据，面板右侧有"关闭所有窗口时"的入口，勾上"Cookie 及其他网站数据"和"缓存的图片和文件"；同一页往下还有"始终清除以下网站的数据"，把网页版的域名加进去，针对性更强。
2. **Edge：**设置 → 隐私、搜索和服务 → 首屏"清除浏览数据"区域 → "每次关闭浏览器时要清除的内容"，把"Cookie 和其他站点数据""缓存的图像和文件"两个开关打开。Edge 的这个入口在近几个版本里从"清除浏览数据"子页挪到了首屏，找不到就往下滚一屏。
3. **Firefox / Safari：**Firefox 走 设置 → 隐私与安全 → 历史记录 → "使用自定义历史记录设置" → 勾"关闭 Firefox 时清除历史记录" → 点旁边的"设置"按钮，把 Cookie、缓存、下载历史都选上。Safari 在 偏好设置 → 通用 → "移除历史记录项目"选"关闭时"，再进 隐私 → 管理网站数据 单独删站点。

系统层的两个开关也顺手配上：Windows 设置 → 系统 → 存储 → 存储感知，把"回收站"的清理周期设成 1 天；macOS 访达 → 设置 → 通用 → "最近使用的项目"数量改成 0。

配完之后有一点要提醒：**这几个开关会让每次关闭浏览器都清掉所有站点数据**，你自己的常用网站也得重新登录。所以它们适合装在公用机、共享笔记本这类"不属于某一个人"的设备上；私人机器上只开"每次询问保存位置"和针对性删除站点数据就够了。

## 手上操作最容易卡住的三个地方

**清完还是登录状态。** 八成是只清了缓存没清 Cookie，或者清的时候时间范围选了"过去 1 小时"。改选"时间不限"，再把站点数据单独删一遍。

**下载压根没落盘。** Chrome 下载栏弹出"已阻止不安全的下载"时，文件确实没写进硬盘，右侧的"保留"不点就什么都没有。Edge 的文案是"无法安全地下载此文件"。这种情况不用去找文件，直接看下载栏状态。

**删到一半报错。** 目标目录在被拔掉的 U 盘上、路径过长、或者目录只读，下载会静默中断，表现是"失败 - 网络错误"或"已中断"。换回默认目录试一次就能判断是权限问题还是网络问题。

## 便签比记性可靠

清单本身不长，难的是在"签完字、赶下一场"的那个当口还愿意花三分钟。我现在的做法是把上面六步压缩成一条便签，贴在包里那张公用电脑的门禁卡背面——看得到，才做得到。如果你也常在这种机器上处理别人的文件，[电报网页版中文指南](https://tlgrlf-web.com) 里关于缓存、Cookie 与共享设备的几节可以对一遍，按浏览器分开写的，对着自己的菜单点不会走偏。
