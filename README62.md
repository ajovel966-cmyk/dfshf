# 老号登进去头像还是前主人的自拍：先关手机号那两个开关，再换 @用户名，简介和头像放末尾——4 个展示位按这个顺序清，前主人才不会继续替你说话

号登进去，头像还是前主人的自拍。驾驶座上拍的，墨镜推到额头上，副驾放着一叠单据。简介写着"中港物流 一条龙 私聊报价"，@ 后面挂着一个我不认识的缩写，通讯录里有个备注叫"老周 拖车"，点开是三天前的对话："明天几点到仓？"

我第一反应是进资料页把头像换成自己的 logo，两分钟搞定。然后锁屏弹了条通知——墨镜脸还在，缓存没刷新而已。那一瞬间我明白了一件事：我改的是自己看得见的那一层，别人看得见的那几层，一层都没动。

这类三年以上、自带好友与频道记录的老号，在 [TG账号批发](https://recadosescraps.com) 上标价 68 元、现货 36 个，买它图的就是那层履历。履历是资产，前主人的身份是负债，两者长在一个号上，只能一层层剥。

## 头像是最不该先动的那一格

改头像有即时反馈：上传、保存，立刻变了，这种反馈会骗人，以为清理已经开始了。真正的判断标准不是"看不看得见"，是**这个字段会被谁、在多少个地方看到**。按暴露半径排，顺序和直觉正好相反。

| 曝光位 | 前主人的痕迹长什么样 | 谁看得到 | 拖到末位改会怎样 |
| --- | --- | --- | --- |
| 群成员列表 | 头像缩略图 + 名字首字 | 群里所有人，包括没跟你说过话的 | 你在群里说第一句话，别人先看到那张脸 |
| 转发消息头部 | "Forwarded from 中港物流-陈" | 每个收到转发的人，以及二次转发的人 | 署名跟着消息一路往下传，你删不掉 |
| t.me 链接与 @ 补全 | @chen_logistics | 拿过名片、看过群公告的所有人 | 旧链接永久指向你，客户以为换人没换 |
| 资料页简介 | 招商文案 + 外部联系方式 | 点开你资料的任何人 | 有人照着那段文案来问价，你得一条条解释 |
| 手机号反查 | 号码还躺在对方通讯录里 | 存过这个号的所有人 | 对方打开 Telegram 就看到"老周"，还能直接发消息 |

头像是"被看到"的问题，手机号和 @用户名 是"被找到"的问题，后者严重一个量级。

## 手机号那两个开关，先关"被找到"那个

路径是 **设置 → 隐私和安全 → 手机号**。这一页有两个独立字段，很多人只关一个就以为完事：

- 谁能看到我的电话号码
- 谁可以通过手机号找到我

只把第一个设成"没有人"，对方资料页那一行确实变隐藏（旧版本是号码打码），但他通讯录里存过这个号，Telegram 会自动把号匹配进他的联系人列表，显示的是前主人的本地备注，点进来照样能发消息。老号的历史联系人本来就杂，客户、司机、货代几十上百条，这一格不关等于门牌号留在原地。

两个都收到"我的联系人"才算把发现层关上。它排第一，因为它决定"别人能不能找上门"；其余几格只决定"找上门之后看到什么"。

## @用户名 改晚了，旧链接会变成别人的名片

路径：**设置 → 编辑个人资料 → 用户名**。t.me/ 后面最少 5 个字符，输入时下面实时提示可用性，被占用是一行红字"此用户名已被使用"（英文客户端是 Sorry, this username is already taken），先想好两个备选。

有个细节得知道：旧用户名改掉之后不会立刻释放，平台会保留一段时间防抢注，"先改走再改回来"这种试探行不通。

它排第二，因为它是唯一能**切断旧入口**的动作。前主人的 @ 被印在群公告、电子名片、半年前的帖子里，那些链接不会因为你换了头像就失效。他叫 @chen_logistics，你顶着这个号谈业务，客户搜一下，出来的还是"中港物流"。

名字跟着一起改。Name 和 Last Name 是两个独立字段，客户端显示的是拼接结果，只动 Name，群成员列表里还是"阿Ken 陈"那种效果，姓氏留空最干净。

## 简介只有 70 个字符，别拿它继续替前主人招商

简介（Bio）上限 70 字符，中文按字符算，超了保存不了。前主人的简介一般是三段式：业务、报价、外部联系方式，是最容易被继承的广告位。

它排在头像之前，因为头像只负责确认，简介负责说服——别人点开资料，先靠那 70 个字判断你还做不做那门生意。写成一句业务定位加一句响应时间，外链别放，那链接可点，等于把流量白送出去。

## 头像放末位，因为它是唯一改完立刻可见的

路径：**设置 → 编辑个人资料 → 点头像 → 拍照或从图库选**。

还有个省事的过渡做法：**隐私和安全 → 头像 → 谁能看到我的头像照片**，设成"我的联系人"。群成员列表里显示一个首字母色块，比一张陌生的新头像更不像"刚被转手"。

两个坑。一是缓存：对方设备存着旧头像，你改完他那边可能还是墨镜脸，得他重开资料页才刷新，别以为没生效就反复上传。二是频率：短时间连续换头像本身是异常行为。

## 五个不显眼、漏了就白清的开关

1. **转发署名**：隐私和安全 → 转发消息 → "谁能在转发我的消息时加上我的账号链接"，默认"所有人"。谁转发你一句话都会挂一条指向你号的链接，等于免费发名片。设"我的联系人"。
2. **最近上线时间与在线状态**：老号的活跃曲线是前主人的作息，这一格不改，别人看到的还是"凌晨三点在线"。
3. **群组和频道 → 谁能把我加进群组**：设"我的联系人"。免费号最多挂 500 个群和频道，前主人可能占了大半，被拉进刷单群、推广群是常态，你的号就成了别人的广告位。
4. **通话 → 谁能给我打电话**：跟手机号可见度联动，一起收到"我的联系人"。
5. **设备 + 两步验证**：设置 → 设备里如果还留着前主人的机型和陌生 IP 归属地，你改什么他都看得见；旧密码在他手上，他随时能把号锁回去。这一格不是展示位，是控制权。

## 清完之后，用另一个号验一遍

在本机看自己，看到的全是缓存和旧数据，必须换个视角。平台上的小号 10 个起批、单价 6.9 元，拿一个当"验收号"很划算：搜手机号、进同一个群看成员列表、转发一条消息看头部。

三个动作全过才算清完：搜手机号搜不到你的号；群成员列表里是色块或新头像，不是那张自拍；转发你的消息，头部没有指向你号的链接。

批量接手的（矩阵那种，一次清十个八个）把上表抄进表格逐项打勾，不然第三天就分不清哪个号停在第几步。

不是你把照片换掉的那一秒。是别人搜不到你、转发不带你、群里认不出你的那一刻——三件事同时成立，这个号才算落到你名下。买老号买的是别人攒了三年的活跃度和通过率，这部分留着；前主人的名字、脸、号码、@ 和那段招商文案，都别留。

30 天换号质保兜的是首登异常，凭订单号免费换号，可它兜不了"客户拿着旧名片来找你"，那种麻烦只有清理顺序能解决。

准备接一个高权重老号，从 [recadosescraps.com](https://recadosescraps.com) 的老号专区看起，下单前把"能不能改绑邮箱"问清楚——改绑拿不到手，这套清理也做不完。拿到号当晚上按顺序过一遍，第二天用验收号回头看，那个号才真属于你。
