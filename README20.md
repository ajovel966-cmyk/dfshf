# 三个月前的一张报价图，我用 Telegram网页版 20 秒捞出来了：搜人、搜文件、搜链接的九条语法与三次筛选实测

上周三下午，客户在群里问去年十二月的报价怎么算的，让我把当时那张图再发一遍。我先在群里往上翻，翻了六屏，手指都酸了，图还是没影。后来换到电脑上，浏览器里打开 **Telegram网页版**，在会话内搜索框里敲了两个字，点了一次日历、一次"媒体"分类，第 19 秒那张图就出来了——缩略图右下角还印着当时的时间戳。

差的不是运气。翻屏和检索之间隔着四件具体的事：入口选哪个、筛选怎么叠、文件靠什么被索引、以及什么情况下搜索压根不会给你结果。这篇只解决一件小事：把一条消息从几千条里揪出来。

登录和界面切成中文的步骤，站点上按图排好了，对着走一遍就行：👉 [Telegram网页版中文指南](https://tlgrgm-web.com)。

## 关键词只敲两个字，等于在全部历史里捞针

网页版有两个搜索口子，位置差很远，效果也差很远。

**左侧栏顶部那个搜索框是全局搜索**，跨所有会话，包括你几个月没点开的群。**聊天窗口右上角的放大镜是会话内搜索**，只在这一个群或频道里找。多数人把活儿交给全局搜索：敲"报价"，得到一串来自十几个人的碎片，翻两页就烦了，然后得出结论"这软件搜不到东西"。

正确的顺序是反的——**先点进那个群，再用会话内搜索**。范围从"所有历史"缩到"这一个群"，命中率立刻不一样。

| 你要找的东西 | 该去哪个入口 | 怎么把范围压小 |
| --- | --- | --- |
| 一张图、一个附件 | 该群的会话内搜索 → 媒体 / 文件分类 | 先按分类过一遍，再叠日期 |
| 某个人说过的话 | 全局搜索或会话内搜索 | 关键词 + `from:`，或点发送者名字 |
| 一个链接、网盘地址 | 会话内搜索 → 链接分类 | 不要用关键词，直接翻分类 |
| 某一天的整段记录 | 会话内搜索 → 日历图标 | 点日期，落到当天最早一条 |
| 跨好几个群出现的同一个词 | 全局搜索 | 结果按会话分组，逐个点开看 |

## 九条语法：哪些真能用，哪些只是传说

搜索框支持一部分操作符，支持得不全，网页版和客户端还不一样。下面这张表是一条条试出来的：

| 写法 | 作用 | 实测结果 |
| --- | --- | --- |
| `报价 十二月` | 空格分隔＝交集，两个词都命中才出 | 有效，比敲一整句好用得多 |
| `"季度结算"` | 要求连在一起出现 | 四字以内有效；长句经常返回空 |
| `from:lin` | 只看这个人发的 | 有效，但只认英文用户名或 ID，中文昵称无效 |
| `#报价` | 找标签 | 只有当初真打了 `#` 的消息才进这个索引 |
| `@频道名` | 直接跳到频道或人 | 全局搜索里最快的一步 |
| `.pdf` `.xlsx` `.jpg` | 按扩展名捞文件 | 有效，比搜正文准得多 |
| `quotation` | 文件名片段 | 有效——它索引的是**文件名**，不索引文档正文 |
| `after:2024-12` `before:2024-12` | 日期范围 | 不支持，别在这上面耗时间 |
| `报价 -拒收` | 减号排除 | 网页版时灵时不灵，换个更窄的词更稳 |

表里有两处要多说一句。倒数第三行是很多人搜不到东西的总根源：**Telegram 不索引 PDF 和 Word 的正文**。你记得那份文件里写着"FOB 深圳"，按这四个字去搜，一条都不会出来——能被搜到的只有文件名。当年存文件时随手留下的名字，决定了一年后的检索成本。

## 搜文件：文件名、扩展名、日历，三段走完

这是最常用的一条路，我把它拆成固定动作：

1. **先点群名**，打开会话信息，点"文件"标签。WebK 界面里这一排是**媒体 / 文件 / 链接 / 语音 / 音乐**。很多时候你要的东西就躺在列表前两屏，根本不用搜。
2. **判断它是什么格式**。三个月前那张报价图，当年多半是微信或手机截图转过来的，扩展名是 `.jpg`，不是 `.pdf`。这一步判断错了，后面全白搭：去"文件"里找截图，永远找不到。
3. **切到"媒体"分类**，打开会话内搜索，点搜索框右侧的**日历图标**，往回翻到那个月，点具体日期。列表会跳到那天最早的一条，然后往下滚。
4. **关键词换成同义词再试一轮**：报价 / quotation / 报价单 / 清单。一次搜不到就换词，不要换着筛选项乱点。
5. **右键另存为，当场改名**。网页版默认落盘的名字是 `photo_2024-12-03_14-22-08.jpg` 或者 `document (17).pdf` 这种，三个月后你自己都认不出来。改名规则用"项目-内容-年月"，例如 `客户A-十二月报价-202412`。

顺手一个配套动作：把浏览器的默认下载目录从"下载"改掉，Chrome 在 `chrome://settings/downloads`，Edge 是 `edge://settings/downloads`，按项目建子目录。默认目录是所有垃圾文件的公共堆场，落进去就等于丢了。更细的路径和命名习惯，站点里单独有一节讲 👉 [文件下载位置与管理](https://tlgrgm-web.com)。

## 搜人：半截用户名比全名好用

中文昵称在搜索里几乎等于不存在。群里那位叫"小林｜华东"的同事，你打"小林"能出几个模糊结果，打"华东"可能一条都出不来，因为客户端认的是用户名（username）那串英文字符。三条可行的路：

- **`@` 加前缀**：知道对方用户名是 `lin_huadong`，敲 `@lin` 就能在下拉里看到人，回车直接进会话。
- **在成员列表里找**：点群名 → 成员，那里的搜索只在成员范围内跑，比全局搜索干净得多，还能按在线状态排序。
- **反向找他说过的话**：在会话内搜索敲关键词，结果里每条消息前面都有头像和名字，点一下名字就变成"只看这个人"，等价于 `from:`。

## 搜链接：别搜，直接筛

链接是最不该用关键词找的一类东西。你在找的往往是 `t.me/` 开头的转发地址、网盘短链、后台登录入口——共同特点是**没有语义关键词**，那串随机字符你根本记不住。

打开会话内搜索，直接点"链接"分类，按时间倒序往下翻。列表里每条都带上下文预览（前后各一行文字），比对着关键词猜快得多。翻到可疑的就点开，看是不是要找的那个域名。

查"这个群发过多少个下载链接"时，这个分类同样比关键词可靠，因为它筛的是消息结构，不是文字内容。

## 三个真会卡住你的地方

**一、报错文案。** 短时间内跨多个群反复搜，页面会先沉默几秒，然后弹一条 `FLOOD_WAIT_` 开头的提示，后面跟一个秒数，意思是要等这么多秒。这时候停手，别接着点——继续点只会把秒数往上涨。等待期间把要搜的词先写在记事本里，回来一次性搜准。

**二、网页版有两个界面。** 地址栏里 `/a` 和 `/k` 是两个不同的前端：`/a` 是旧界面，会话内搜索只有分类标签，**没有日历，也没有发送者筛选**，`from:` 会被当成普通文字参与匹配；`/k` 才有日历和筛选条。照着别人的截图找不到按钮，先看一眼自己在哪一版。

**三、搜索框没反应。** 敲字不出结果、结果区一直转圈，先开一个无痕窗口（Chrome 和 Edge 都是 `Ctrl + Shift + N`，Firefox 是 `Ctrl + Shift + P`）复现一次。无痕里正常，就是某个扩展在拦请求，逐个关掉排查。清缓存也能修好，但登录状态一起没，得重新扫码——细节在 👉 [缓存与 Cookie 说明](https://tlgrgm-web.com)。

再补一条中文特有的：**一个字搜不出东西，不是坏了，是太宽**。输"表"会列出几百条然后卡死，输"报价"才收敛。两个汉字起步，是中文检索的最低门槛。

## 一套照着做就行的三十秒流程

1. 先定形态：我要的是一张图、一份文档，还是一句话。
2. 点进目标会话，不从全局搜索开始。
3. 打开会话内搜索，先点分类（媒体 / 文件 / 链接），别急着输词。
4. 需要定位时间，点日历选到那一周；需要定位人，叠 `from:` 或点发送者名字。
5. 命中后右键另存，当场按"项目-内容-年月"改名。
6. 把这条消息转发进自己的资料库频道，下次复盘不用再搜。

## 搜索能救急，结构才不用救

那次找图，真正的原因不是我不会用搜索，是那个群什么都往里扔——报价图、闲聊、物流签收截图、转发新闻，全挤在一条时间线上。搜索是补救手段，结构才是预防。

给关键会话定三条就够：发文件时在同一条消息里写清"这是哪个项目哪个月的什么"，让文字和附件绑在一起；每个项目建一个只有自己的频道当索引，只往里转结论和确认原话；另存时统一命名。三条做完，搜索会越用越少——东西本来就在手边。
