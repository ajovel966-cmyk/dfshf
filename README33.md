# 网吧登录过电报、走时只关了标签页：公用电脑上把 Telegram 网页版退干净的 4 个动作

上周去网吧赶一份报价，靠窗那台机子上我用网页版回了三条客户消息，顺手把一个 8MB 的表格从群里转存到桌面。下机前我做了自以为很干净的一套：关标签页、把桌面上的文件拖进回收站、起身走人。三天后翻手机端的设备列表，那台机器还挂在那儿——Chrome、Windows、登录时间就是我在网吧的那一晚，一条没少。

这里有个反直觉的地方：网吧机器大多装了还原卡，重启就恢复出厂，硬盘上一点痕迹都不剩。可账号那边的那条授权不归还原卡管——它记的是"某天有一台 Chrome 登录过这个账号"，跟那台机器现在干净还是脏没关系。

所以清本机、退登录、作废会话，是三件独立的事。我按这个思路重排了走之前的两分钟：手机上先掐掉那条授权，电脑上再退再清，然后对着清单自查一遍。

## 三件事作用在不同层面，混着做等于白做

"退出""清数据""结束会话"平时被当成同一个动作的三种说法。它们在三个地方生效，谁也替不了谁。

| 动作 | 作用在哪一层 | 做完之后 | 没做会怎样 |
| --- | --- | --- | --- |
| 关标签页 / 关浏览器 | 什么都没变 | 只是窗口没了 | 同一台机器再打开就是聊天列表 |
| 退出登录（Log out） | 这台机器的这个浏览器 | 本机凭证被删，页面回到扫码界面 | 页面看着关了，凭证还在，浏览器会自己续上 |
| 清站点数据 | 本机残留：缓存、localStorage、IndexedDB、站点权限、自动填充、下载记录 | 这台机器上看不出你来过 | 地址栏建议、自动填充、下载目录都还留着线索 |
| 结束会话（手机端终止） | 账号侧的授权记录 | 那一条当场失效，本机残留再多也进不去 | 本机一旦被还原，你就再也找不到这条记录去掐它 |

表格第四行是关键。前三个动作都在本机身上使劲，只有"结束会话"是从账号侧下刀。公用电脑最大的风险不是"别人能看到聊天列表"，而是"你走了以后连自己都查不到那次登录"——机器还回去、系统被还原，本机线索全断，只剩手机端那条记录替你记着。

顺序也就定下来了：先在手机上终止会话，再在那台机器上退出登录，然后清站点数据，末尾对着清单自查一遍。倒过来做容易卡住——清数据清到一半，页面正卡在转圈或二维码出不来，这时候你既退不出去，也确认不了自己到底退没退。

## 动作一：手机上把那一次授权掐掉

手机 Telegram → 设置 → 设备（Devices）→ 活跃会话。每条记录写着设备类型、浏览器名称、大致登录地点和登录时间。找到对不上的那条，点进去，选终止会话（Terminate Session）。

这一步的价值在于它不依赖那台电脑：机器关了、还原了、被下一个人重装了，都不影响你从手机端把这条作废。几个实操上的判断：

- 网页版登录后，这条记录的设备名通常显示浏览器名加系统类型，比如 Chrome、Windows；网吧同一时段可能冒出两三条同类记录，认时间而不是认名字。
- 只关标签页不会让这条消失，在本机点退出也未必立刻消失——退出删的是本机凭证，列表里那条要过一阵才同步掉。别拿"列表还在"当没退成功，也别拿"列表没了"当退干净。
- 两个月前在别处登过、地点明显对不上的记录，一并终止。留着不占地方，但它是一条活着的入口。

## 动作二：在那台机器上真点一次退出

回到那台电脑（如果还回得去），网页版左侧菜单拉到底 → 设置（Settings）→ 最下方 退出登录 / Log out，弹窗问一句 Are you sure you want to log out?，点确认，页面回到扫码界面。**看到二维码才算退成功。**

关标签页、关浏览器、按电源键关机，三个都不算。还有个常见误会：桌面客户端的 Ctrl+L 是锁屏（Lock screen），输个本地密码就回去了，跟退出登录是两码事，很多人把它当退出用。

## 动作三：只清这一个站点的数据

整锅端是公用机上最容易犯的错——清完邮箱、网银、公司后台的登录一起没了，而你未必有权限把它们一个个登回来。按站点清：

- **Chrome**：地址栏输 `chrome://settings/content/all`，搜索框填站点域名，点进条目选删除；或者 设置 → 隐私和安全 → 删除浏览数据，时间范围选"过去 1 小时"，只勾"Cookie 及其他网站数据"，别勾"密码"和"自动填充"。
- **Edge**：`edge://settings/siteData`，搜索域名，条目右侧垃圾桶。
- **Firefox**：设置 → 隐私与安全 → Cookie 和网站数据 → 管理数据，搜索后删除。
- **Safari**：设置 → 隐私 → 管理网站数据，搜索后移除。

顺带纠正一个说法：Ctrl+Shift+R 硬刷新不等于清数据。它只让浏览器重新下载图片和脚本，Cookie、localStorage 原地不动，刷新完该直接进还是直接进。

## 动作四：把本机上的实物痕迹收走

这一步跟登录状态无关，纯粹是别把东西留给下一个人。

1. **下载目录**。网页版存下来的文件默认落在浏览器下载目录，文件名常是 media_ 开头的一串，扩展名可能是 .webp、.mp4、.pdf。Ctrl+J 打开下载记录，右键"在文件夹中显示"，删掉文件，再回列表里清掉这条记录。
2. **自己另存的那份**。桌面、文档里手动保存的表格，以及导出的聊天记录（Export chat history 的产物是一个 HTML 加一堆附件文件夹），不在浏览器管辖范围内，得自己找一遍。
3. **剪贴板**。Win+V 的剪贴板历史里可能还躺着刚复制的号码、验证码、一段聊天原文，逐条删；公用机上索性用完就清空。
4. **通知中心**。Win+N 里可能留着带内容的预览，一条条划掉。
5. **自动填充**。`chrome://settings/autofill` 里把手机号那几条删掉。公用机让浏览器记住号码，等于给下一个人省了一步。

## 走之前两分钟：残留自查清单

清完不代表清干净了，得有一条能一票否决的检查。

| 查什么 | 怎么查 | 算干净的标准 |
| --- | --- | --- |
| 会不会直接进聊天列表 | 新开标签页，手动输域名 | 停在扫码或登录页 |
| 站点数据在不在 | `chrome://settings/content/all` 搜域名 | 搜不到条目 |
| 设备列表 | 手机端 设置 → 设备 | 没有刚才那条，或标着已终止 |
| 下载 | Ctrl+J | 列表为空，文件夹里没有 media_ 文件 |
| 剪贴板 | Win+V | 没有刚复制的内容 |
| 自动填充 | `chrome://settings/autofill` | 没有该号码 |

第一行是唯一不能骗人的一条：前面全清完，打开还是聊天列表，说明还有别的东西在替你记着。要么是同一账号在另一台设备上没退，要么是你在这台公用机上登了浏览器账号——Edge 和 Chrome 登了同一账号，书签、扩展、自动填充会跟着同步，站点数据也可能被带着还原回来。公用机上别登浏览器账号，走了顺手退掉。

## 几个会让人误判的细节

- 退了又登、登了又退，短时间反复几次，登录会被限流，页面弹 `Too many attempts, please try again later.`，或者提示要等若干分钟。这不是账号被封，是频率限制，停十几分钟再试，别接着点。
- 网页版有两套界面，`web.telegram.org/a` 和 `/z`，退出入口位置不完全一样：一套在 Settings 列表最下方，另一套从左侧栏头像点开。
- 无痕窗口登录，关窗即失效，是公用机上最省事的用法；但无痕窗口里下载的文件照样落进真实下载目录，这一点很多人以为跟着窗口一起消失了。
- 还原卡管硬盘，不管账号。它的存在会让人产生"机器干净了"的错觉，而你要处理的那条记录在账号侧。

## 把"下次不敢用"变成"下次随便用"

我现在在别人的机器上用完，固定四个动作，顺序不变：手机端终止、本机退出、只清这个站、扫一眼下载和剪贴板。整套下来不到三分钟，比事后跟人解释"我那个号可能被人看过"省事太多。
