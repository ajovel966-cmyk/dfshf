# 手机号停机三个月，网页版把我锁在登录页外：换号迁移的 7 个动作、5 条真会丢号的风险

旧手机号停机了，网页版一直登不进去。那张卡是 2015 年办的，去年家里改宽带业务，营业厅顺手把副卡一起销了，我当时只当是每月省下十几块。三个月后我在公司电脑上打开 web.telegram.org，输入那串用了八年的号码，点下一步，转两秒圈，弹回一句 `Too many attempts, please try again later`。再点几次，连这句提示都没了，只剩一个不动的按钮。

我第一反应是"换个号重新注册一个不就完了"。点进注册流程才想明白：那个号后面挂着三个工作群、两个只看不说话的频道、一份从 2019 年攒到现在的收藏夹。重新注册等于清零，还得挨个去群里解释"我是原来那个谁"。

所以这篇只讲一件事：**旧号用不了了，账号怎么跟着人搬过去**。前半段是还能救的走法，后半段是救不回来的走法，两者顺序完全相反——先对号入座，能省掉半天无用功。文中那些分项步骤，我是对着 👉 [Telegram网页版中文指南](https://tlgroa-web.com) 的目录一条条比着做的，号码、权限、Cookie 三块是分开的，卡在哪块翻哪块。

## 一、先分清自己站在哪一档

换号的成败几乎在你动手之前就定了，取决于还有没有一台设备保留登录态。

| 你现在的处境 | 网页版的样子 | 原账号能不能保住 | 该走哪条路 |
| --- | --- | --- | --- |
| 手机或桌面客户端还登着 | 网页版可能已掉线，不影响 | 能，而且是干净的一次迁移 | 在活着的设备里改绑定号码，别碰网页版 |
| 只剩一个网页版标签页还开着 | 刷新还能进，聊天记录能翻 | 能，但窗口期很短 | 先别关标签页、别清缓存、别开无痕 |
| 全部退出，旧号也停机 | 停在登录框，收不到任何码 | 看你还记得什么 | 走恢复申诉，成败取决于邮箱与两步验证 |

中间那一档最容易被自己弄丢。很多人一看网页版还能进，就顺手清一次浏览数据，或点"退出登录"重登一遍——**这一步就是把仅剩的那根绳子剪断**。Cookie 和会话是同一个东西，清掉之后旧号收不到码，你从第二档掉进第三档。

## 二、还有活着的设备：七个动作，一次做完

只要还有一台手机或桌面客户端在线，换号就是设置里的一次操作，不需要旧号配合。最救命的细节是：**换号验证的是新号码**。很多人以为"必须先收到旧号的验证码才能改"，于是拿着停机的卡干等。

1. **先护住网页版**。别关标签页，别按 Ctrl+Shift+Delete，别用无痕重开。Chrome 启动设置里选"继续浏览此前打开的网页"，下次开浏览器标签页还在。
2. **找一台还登着的设备**。手机端进「设置」，头像下面那一栏点「编辑」；Windows / macOS 桌面端进「设置」，同一位置写的是「编辑资料」。两处入口名字不一样，位置一样。
3. **点「更改号码」**。这一项在「编辑」面板里，排在用户名和简介下面。网页版没有这一项，翻遍设置也找不到，这是产品本身的缺口，不是你没找对地方。
4. **填新号码，连国家码一起选**。国家/地区下拉手动选，本地号码去掉开头的 0。填完看一眼输入框里回显的完整号码，位数对不对。
5. **验证码发到新号上**。收码通道就三条：新号的短信、新号所在手机上已登录会话的站内消息、以及运营商的语音播报兜底。旧号在这里完全不参与。
6. **确认后核对两处**。「编辑」面板应显示新号码；「设置 → 设备」里的设备还都在，登录状态不会因为换号被踢。
7. **回到网页版按一次 F5**。只刷新，不清数据。标题栏还挂着旧号码就退出重进一次；实在不行关掉标签页，从收藏夹重新进。

聊天记录跟着账号走，不跟着号码走，换号不需要备份迁移。「同步联系人」那个开关只决定要不要把新号码通讯录里的人拉进电报，跟账号安全无关。

## 三、全部退出之后：这才是真正的硬仗

如果一台设备都没留住，网页版输入旧号只会撞上几种固定反馈，看清楚它们分别意味着什么：

- `PHONE_NUMBER_UNOCCUPIED`：号码在系统里已不存在。不是密码错，是这个号被回收、账号随之注销。
- `PHONE_NUMBER_BANNED`：号码被系统封了，跟停机无关，多出现在号码被反复注册的情况。
- `FLOOD_WAIT_x`：`x` 是秒数，短则几十秒，长则一整天。这是限流，不是故障，越点越久。
- 按钮直接变灰、没有任何提示：客户端连错误码都没拿到，多半是请求在网络上被掐了。

这个阶段能做的只剩两件：在登录页翻「无法登录？」那条链路，用还能收信的邮箱接恢复验证码；或者如果记得两步验证密码，在任意客户端上把账号拉回来。两样都没有，就只能等。

## 四、五条真会把账号弄丢的风险

| 风险 | 触发条件 | 实际表现 | 提前怎么防 |
| --- | --- | --- | --- |
| 号码被回收后被接管 | 停机后运营商的号码冷冻期结束，号被重新放号 | 新机主注册时走到"该号码已有账号"的分支，你的会话被顶掉 | 停机前一周就把绑定号码换掉，别拖 |
| 清缓存把仅剩的绳子剪断 | 手动清 Cookie、无痕窗口、浏览器大版本更新后重置 | 网页版回到登录页，旧号收不到码 | 清之前先确认还有别的设备在线 |
| 在登录页上试图"换号" | 以为登录框里能改号码 | 反复取码、反复限流，`FLOOD_WAIT` 越来越长 | 换号只在已登录的会话里做 |
| 设备列表没清 | 换号后没检查登录记录 | 旧手机、旧电脑仍能翻聊天记录 | 「设置 → 设备」逐个看，不认识的直接终止 |
| 两步验证密码丢失 | 换号后忘了当初自己设的密码 | 新设备登录卡在密码那一步，没有"找回"按钮 | 设完抄在纸上，别只存手机备忘录 |

第一条是唯一不可逆的，其余四条靠操作顺序就能救：先保设备、再改号、后清缓存，顺序反过来做，就有掉进第三档的可能。

## 五、换号那天的三个浏览器细节

同一件事在四个浏览器里的入口位置不同，换号那天最容易在这反复折腾。

Chrome 清的是站点级数据：`设置 → 隐私和安全 → 网站设置 → 查看权限和网站数据`，搜索框敲 `web.telegram.org`，点进去就是 Cookie 和站点数据。这一下删的是整个站点的会话，不是"清一下缓存"那么轻。

Edge 的路径是 `设置 → Cookie 和网站权限 → 所有权限和站点数据`。Firefox 在 `设置 → 隐私与安全 → Cookie 和网站数据 → 管理数据`。Safari 要用菜单栏 `Safari → 设置 → 隐私 → 管理网站数据`，在 Windows 上这个菜单叫「编辑」，容易找错。

还有一个版本层面的事：网页版有两套前端，`web.telegram.org/k/` 和 `web.telegram.org/z/`，`/a/` 会按浏览器标识自动跳。两套界面设置项名字略有差别，但**都没有更改号码入口**，也都有「设置 → 设备」。手机端同理，iOS 上叫「编辑」，安卓上叫「编辑资料」。

换完号顺手把浏览器权限重配一遍：通知要过系统和站点两道门，下载目录单独指定。这两项在 [浏览器缓存清理指南](https://tlgroa-web.com) 和 [Cookie 与登录状态说明](https://tlgroa-web.com) 里是分开写的。

## 六、迁移完成后 24 小时内该收的尾

1. 打开「设置 → 设备」扫一遍登录记录，旧手机、旧平板、公司电脑，不认识的当场终止。
2. 开两步验证，密码写纸上。开了之后，光有验证码也进不来，这是换号之后最值钱的一道墙。
3. 网页版单独配站点权限：通知、下载目录、剪贴板。下载目录别用默认的"下载"文件夹，公用电脑上这点差别不小。
4. 入口放收藏夹，存自己敲出来的地址，不是群里转的短链。仿站不会做得粗糙，只会比原版更"正规"。

## 号码是钥匙，房子得自己盖

那两天折腾下来，我最大的收获不是学会换号，而是弄明白了一件事：手机号只是进门的钥匙，账号里的东西才是房子。配钥匙得快，趁你还在屋里的时候配——人在屋里，改个绑定号码就是点几下；人被关在门外，就只能隔着门跟系统解释你是谁。

我现在给还在用旧号的朋友只留一句提醒：**在停机之前动手，别在停机之后补救**。真拖到收不到码那一步，先别反复点重发，先确认还有没有一台设备亮着——那台设备就是你当时唯一的门。
