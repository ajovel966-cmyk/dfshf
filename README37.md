# 登进去先别回消息：网页版头五分钟该改的四项设置，我按秒排了张顺序表

凌晨一点半，我在书房那台重装过系统的旧笔记本上打开网页版，扫码进去的一瞬间整个人有点懵：左边一列 `Settings`、`Contacts`、`Saved Messages` 全是英文，右边消息列表挂着 913 条未读，红点从置顶一直排到屏幕底下。我本来只想回一条客户的消息，结果先花了十分钟找语言在哪改，又花了五分钟搞明白为什么桌面右下角死活不弹通知。

那次之后我把"登录成功之后"这段路单独拆了出来。**登录只解决"能不能进去"，进去之后的前五分钟决定你接下来用着顺不顺。** 顺序不是随便排的：界面认不出来就找不到菜单，消息不收口就一直被红点牵着走，隐私和安全的开关放后面——因为它们最容易在"急着回消息"的时候被跳过。

这篇只讲这五分钟。菜单名、路径、会看到的提示文案我都按实机写，配图版本可以对着 👉 [Telegram网页版中文指南](https://tlgrwo-web.com) 里的章节一起看。

## 五分钟怎么分：先界面，再消息，然后隐私，收尾安全

| 时间窗 | 改什么 | 主要入口 | 拖到以后再改会怎样 |
| --- | --- | --- | --- |
| 0:00–1:00 | 界面：语言、时间格式、发送键、主题 | 左上角三横线 → Settings → Language | 菜单全靠猜，后面每一项都要多花两三倍时间 |
| 1:00–2:00 | 消息：未读收口、通知权限、消息预览 | 会话列表右键 + 浏览器站点权限 | 红点一直挂着，锁屏预览把聊天内容漏出去 |
| 2:00–3:30 | 隐私：自动下载、手机号可见性、上线时间 | Settings → Privacy and Security / Advanced | 群里几十个视频自动落盘，手机号对陌生人可见 |
| 3:30–5:00 | 安全：活动会话、两步验证、退出路径 | Settings → Devices / Privacy and Security | 别人设备上的旧会话一直挂着，公用机器上账号留着 |

四项里只有界面是"必须马上做"的，其余三项都是"现在花一分钟、以后省很多"的类型。我按这个顺序排，是因为改完界面之后再看英文菜单项就不会卡壳。

## 0:00–1:00 界面：把英文换成看得懂的，顺手改三个小地方

网页版的语言开关藏得不深，但两个版本的入口位置不一样，这点很多人卡住：新版（地址栏里带 `webk` 的那套）三横线在左上角，旧版（`weba`）在左侧栏底部偏下。点开之后进 `Settings`，第一屏就能看到 `Language`，下拉里选「中文（简体）」，也有的版本写 `Chinese (Simplified)`。

切换的一瞬间页面会整块重载一次，这是正常的。如果选完还是英文，多半是语言包没拉下来——刷新一次（`Ctrl + F5` 强制刷新），或者先把扩展全关掉再试，广告拦截类扩展把语言包的请求拦掉是常见原因。更细的分步说明在站内的 [中文界面设置方法](https://tlgrwo-web.com) 那一节，按浏览器分着写。

语言通了，顺手改三个真正影响日常手感的项，都在 `设置 → 通用`（部分版本叫 `聊天设置`）里：

1. **时间格式**：改成 24 小时制。12 小时制在跨时区沟通里最容易看错，"下午 3 点"和"凌晨 3 点"只差两个字母。
2. **发送键**：默认是 `Enter` 直接发。你要是习惯写长消息、爱换行，改成 `Ctrl + Enter` 发送，误发率立刻下来。
3. **主题**：夜间用就切深色。深色主题下未读小红点的对比度更低，眼睛没那么累。

字号别在浏览器里用 `Ctrl + +` 一路放大，那会把整个页面（包括侧栏）一起撑开，排版歪得厉害。要调字号去 `设置 → 聊天设置 → 消息文字大小`，只动消息正文。

## 1:00–2:00 消息：红点和通知是两件事，分开处理

913 条未读里真正需要我回的不到十条。这时候别一条条点，按下面这个顺序收口：

1. **先清红点，不读内容**。在会话列表里对不想立刻处理的会话点右键，选 `标记为已读`（`Mark as read`）。置顶的几个留着，剩下的红点一次性扫掉，视觉噪音立刻少一半。
2. **关掉消息预览**。路径是 `设置 → 通知`，把 `消息预览`（`Show Preview`）关掉。开会投屏、锁屏放在桌上，弹出来的第一条就是聊天原文，这个开关是唯一能挡住的。
3. **配浏览器通知权限**。这一步最容易只做一半：系统层面允许浏览器发通知了，浏览器层面却没给这个站点开权限，结果就是不弹。Chrome 走 `设置 → 隐私和安全 → 网站设置 → 通知`，在列表里找到站点改成"允许"；Edge 是 `设置 → Cookie 和网站权限 → 通知`；Firefox 在 `设置 → 隐私与安全 → 权限 → 通知 → 设置`，把站点加进允许列表；Safari 在 `设置 → 网站 → 通知`。
4. **权限改完必须刷新**。已经打开的标签页不会自动继承新权限，`F5` 之后才生效。没生效时页面顶部会挂一条灰条，英文是 `Notifications are blocked`，中文版写「通知已被阻止」，地址栏左边的小图标上还会带一个红色斜杠。

顺带把免打扰定好：`设置 → 通知 → 免打扰` 里设一个时间段，比如 23:00 到 08:00。这个开关和浏览器的通知权限是叠加关系，两边都开才会真的静音。

## 2:00–3:30 隐私：四个默认开着、你未必想要的开关

这一段是我认为五分钟里性价比最高的，因为它改的都是"默认帮你打开"的项：

- **自动下载媒体**。路径 `设置 → 高级 → 自动下载媒体`。默认在 Wi-Fi 下照片、视频、文件全自动下。一个 200 人的群，一晚能往硬盘里塞两三个 G。我的做法是照片留着，视频和文件全关。
- **手机号可见范围**。`设置 → 隐私和安全 → 电话号码`，改成「没有人」。改完陌生人只能看到你的用户名，看不到号码。
- **最近上线时间**。同一页的 `最近上线时间`，可以设成「没有人」或者「我的联系人」。做跨境对接的人尤其该关，客户能从在线时间反推出你的作息。
- **通过手机号找到我**。还在这一页，关掉。关掉之后别人拿你的号码搜不到你的账号，被误加的概率降一大截。

文件下载位置也该在这时候定下来：浏览器 `设置 → 下载内容 → 位置`，单独指一个目录，别让它往默认的"下载"文件夹里堆。群里一天几十个文件进去，一周之后你自己都分不清哪个是合同哪个是表情包。

## 3:30–5:00 安全：会话、两步验证、退出路径

收尾这段只有三件事，但少了任何一件，前面四分钟都白做。

1. **看活动会话**。`设置 → 设备`（`Devices`），这里列出所有登录中的设备，带设备名、浏览器、大致地点和最近一次活跃时间。看到不认识的、或者地点对不上的，直接点 `终止会话`。我从旧笔记本上登过之后忘了退，这里躺着一个三个月前的记录。
2. **开两步验证**。`设置 → 隐私和安全 → 两步验证`，设一个自定义密码，再填一个恢复邮箱。注意恢复邮箱要收验证码才能绑定，绑完这个邮箱就是唯一的重置入口——别用一个自己不常看的邮箱。
3. **把退出路径记熟**。网页版的退出在左上角菜单最底部，`退出登录`（`Log out`）。点右上角叉只是关标签页，账号还挂在里面。清 Cookie 也能退，但会连所有站点的登录状态一起清，代价比点一下按钮大得多。

如果你用的是别人的机器，`3:30` 这一分钟里再加一个动作：走之前按 `Ctrl + Shift + Delete` 打开清除浏览数据，时间范围选"过去一小时"，勾上 Cookie 和缓存，清完再关窗口。

## 五分钟之后：这套动作真正的用处

这四项设完，界面上看不出什么大变化——没有新功能，没有变快，唯一的变化是你不再被红点牵着走，也不再在开会投屏的时候手忙脚乱地点弹窗。

我后来的习惯是：**每换一台设备登一次，就把这五分钟重走一遍**。网页版有个特点，设置分两层存：语言、主题、隐私这些跟着账号走，换机器还在；通知权限、下载目录、缩放这些跟着浏览器走，换机器就归零。所以第二台设备上真正要重做的往往只有通知和下载两处，一分钟够了。

站上把这几节按浏览器分开写了，遇到具体某个开关找不到，可以直接翻 [Chrome 浏览器使用建议](https://tlgrwo-web.com) 或者通知那一章对着看。五分钟不算长，但它决定了你后面是"用工具"还是"被工具催"。我现在登进去的第一件事仍然是看语言对不对——不是怕看不懂，是怕自己又忘了当初那 913 条未读是怎么堆起来的。
